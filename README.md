## About

**BRUPY_BRUTE_FORCE** is a Python project developed for learning HTTP authentication testing and offensive security techniques in authorized environments.

### Features

- HTTP/HTTPS endpoint validation
- Custom username and wordlist path
- Configurable request timeout
- HTTP response status inspection
- Redirect and response size analysis

## Installation

```bash
git clone https://github.com/MarkDevBrasil/BRUPY_BRUTE_FORCE.git
cd BRUPY_BRUTE_FORCE
pip install requests
```

## Usage

```bash
python main.py
```

Follow the interactive prompts to configure the target URL, test username, wordlist path and timeout.

## Project Status

**Under development.** Automated wordlist-based password attempts are not implemented in the current version.
